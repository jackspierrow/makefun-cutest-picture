# Make the cutest picture — make.fun entry

Bounty: https://make.fun/bounty/cutest-picture-01 ($250, ends Fri 13 Nov 2026 17:00 WIB)

## The picture

A tiny fluffy baby red panda wearing an oversized hand-knitted strawberry
hat, hugging a small warm steamed bun, with huge sparkling eyes, soft pastel
pink background and floating cherry blossom petals.

## How it works

`main.py` copies the bundled `entry.png` to `/output/entry.png`, byte for
byte. No network, no randomness — two runs write identical bytes.

## Run

```sh
python3 main.py
```
